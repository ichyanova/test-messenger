## Green API Telegram Client

### Описание

Клиент для отправки и получения сообщений в Telegram через Green API.
Интерфейс стилизован под Telegram Web (светлая тема).

### Функциональность

- Авторизация через данные из личного кабинета Green API (idInstance и apiTokenInstance)
- Создание нового чата по номеру телефона
- Вывод списка чатов с сортировкой по последнему сообщению
- Отправка и получение сообщений в Telegram (только текстовые сообщения, без цитат и медиа)

### Стек

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Lucide Icons

### Установка и запуск в режиме разработки

```
npm install
npm run dev
```

Доступ по адресу http://localhost:5173

### Подготовка к отправке и получению сообщений через сервис Green Api

Для отправки и получения сообщений через сервис Green Api необходимо иметь **idInstance** и **apiTokenInstance**.
Эти данные можно получить в личном кабинете Green Api:

1. Зарегистрируйтесь в [личном кабинете](https://console.green-api.com/registration).
2. Создайте инстанс **Telegram: Developer**
3. Авторизуйте инстанс удобным способом и дождитесь статуса `Авторизован`.
4. В настройках уведомлений
   – оставьте поле "Адрес отправки уведомлений (URL)" пустым
   – включите «Получать уведомления о входящих сообщениях и файлах»
   – включите «Получать уведомления о сообщениях, отправленных с телефона»
   – включите «Получать уведомления о сообщениях, отправленных с API»
   Сохраните изменения и подождите до 5 минут.
5. Скопируйте `idInstance` и `apiTokenInstance` и введите их на экране входа.
