## Green API Telegram Client

### Описание

Клиент для отправки и получения сообщений в Telegram через Green API.
Сейчас работает только вход через getStateInstance. Сайдбар и чат — заглушки

### Функциональность

- Авторизация через данные из личного кабинета Green API (idInstance и apiTokenInstance)
<!-- Отправка и получение сообщений в Telegram -->

### Стек

- React
- TypeScript
- Vite
- Tailwind CSS

### Установка

```
npm install
npm run dev
```
